## Cardiovascular Disease Prediction Using Machine Learning

## Project Overview
This project uses machine-learning algorithms to predict the presence of cardiovascular disease based on clinical attributes.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
